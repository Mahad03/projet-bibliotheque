# A lire vite

Projet de bibliotheque en `Node.js` avec `Express` et `Sequelize`.

Fichiers utiles :

- `serveur.js`
- `modeles/index.js`
- `routes/`
- `controleurs/`

Pour tester :

- importer `collection-postman-bibliotheque.json`
- ou lancer `npm run verifier-api`
